Improved the error message shown when ``--pyargs`` is given a module that is importable but whose source files are not available on the file system -- for example when running inside a frozen or zipped application (such as a PyInstaller bundle). Previously pytest reported the misleading ``module or package not found: ... (missing __init__.py?)``; it now explains that the module was found but its file-system path does not exist, and that pytest can only collect tests from files available on the file system.
