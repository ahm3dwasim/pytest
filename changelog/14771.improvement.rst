Improved the error message shown when ``--pyargs`` is given a module that the import system finds but whose files are not available on the file system, for example inside a frozen or zipped application (such as a PyInstaller bundle). The ``module or package not found`` error now explains that the module was found but its path does not exist, and that pytest can only collect tests from files on the file system. This does not add support for collecting tests from frozen applications.
